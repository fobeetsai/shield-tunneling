### 🚀 如何直接 PO 到網路上（1 分鐘免費發布）：
#### 方法一：Netlify Drop（最推薦、免寫程式碼、30秒完成）
1. 打開瀏覽器訪問：https://app.netlify.com/drop
2. 將本資料夾（`潛盾隧道工程_中日對照網頁發布版`）或包含 `index.html` 的資料夾直接**拖曳（Drag & Drop）**到網頁方框中。
3. 系統將在 10 秒內生成一個正式的公開網址（例如：`https://shield-tunneling-manual.netlify.app`），即可發給日籍工程師、台籍工程師與口譯學員！

#### 方法二：GitHub Pages
1. 建立一個新的 GitHub 倉庫（例如：`shield-tunneling`）。
2. 將此 `index.html` 上傳至倉庫根目錄。
3. 在倉庫「Settings」->「Pages」將來源設為 `main` 分支並儲存。
4. 即可獲得：`https://<你的帳號>.github.io/shield-tunneling/`。

#### 方法三：Vercel
1. 訪問：https://vercel.com
2. 匯入或將本目錄拖曳上傳即可秒級上線。

#### 方法四：內部雲端伺服器 / 內網 NAS / Google Drive
* 直接將 `index.html` 上傳至 Apache / Nginx / AWS S3 / Google Cloud Storage 靜態網站 Hosting 即可。
