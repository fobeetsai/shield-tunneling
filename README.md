# 土木捷運・潛盾隧道整體工程全面術語庫・互動檢索與複習系統
## Comprehensive Civil & Shield Tunneling Trilingual Knowledge Base (TW / CN / JA / EN)

🔗 **線上公開網址 (GitHub Pages)**：[https://fobeetsai.github.io/shield-tunneling/](https://fobeetsai.github.io/shield-tunneling/)

---

### 📖 系統簡介
本系統彙整臺灣捷運工程局 (DORTS)、中國大陸隧道與地下工程規範、日本土木學會示方書及 CF763 東環段等全專案工程術語，涵蓋 **13 大土木捷運與隧道工程全領域**，共計 **6,367 條專業中日英繁簡對照術語**。

### 🌟 核心功能
1. **📋 總表檢索模式**：
   * 新增 **【簡體中文 (符合大陸用語)】** 專屬欄位，落實工程專業用語在地化（如：潛盾➔盾构、環片➔管片、連續壁➔地下连续墙／地连墙、背填灌漿➔壁后注浆、發到達井➔始发／接收井、地盤改良➔地层加固等）。
   * 支援臺灣繁體、大陸簡體、標準日文、讀音假名、英文、工程說明與現場防錯提醒之全域即時搜尋。
   * 支援 13 大專業分類、重要度等級（A 核心必會 / B 現場常用 / C 專門術語）與學習狀態過濾。
2. **🗂️ 抽認卡複習模式**：翻面記憶訓練，支援鍵盤快捷鍵（`[空白鍵]` 翻面、`[←]` 待複習、`[→]` 已熟練），翻面同步呈現大陸規範用語標籤。
3. **✍️ 隨堂自測練功**：隨機產生四選一中日規範對應測驗，即時回饋並呈現兩岸規範與工程防錯重點解析。
4. **⭐ 收藏與學習追蹤**：全本機記憶保存已掌握、待加強與自訂星號收藏詞彙。
