# 土木捷運・潛盾隧道整體工程全面術語庫・互動檢索與複習系統
## Comprehensive Civil & Shield Tunneling Bilingual Knowledge Base & Flashcard System

🔗 **線上公開網址 (GitHub Pages)**：[https://fobeetsai.github.io/shield-tunneling/](https://fobeetsai.github.io/shield-tunneling/)

### 📖 系統簡介
本系統彙整臺灣捷運工程局 (DORTS)、日本土木學會規範、CF763 東環段等全專案工程術語，涵蓋 **13 大土木捷運與隧道工程全領域**，共計 **6,367 條專業中日英對照術語**。

### 🌟 核心功能
1. **📋 總表檢索模式**：支援中文、日文、讀音假名、英文、工程說明與口譯提醒之全域即時搜尋，支援 13 大專業分類過濾與分頁瀏覽。
2. **🗂️ 抽認卡複習模式**：翻面記憶訓練，支援鍵盤快捷鍵（`[空白鍵]` 翻面、`[←]` 待複習、`[→]` 已熟練），內建日語/華語語音朗讀。
3. **✍️ 隨堂自測練功**：隨機產生四選一中日規範對應測驗，即時回饋並記錄學習答對率。
4. **⭐ 收藏與學習追蹤**：全本機記憶保存已掌握、待加強與自訂星號收藏詞彙。
